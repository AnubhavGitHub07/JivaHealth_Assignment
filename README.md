# Jiva Health Dashboard

A modern healthcare admin dashboard built using React, TypeScript, Tailwind CSS, and shadcn/ui.

This project was developed as part of a frontend assignment and focuses on clean UI architecture, responsive design, reusable components, and smooth user experience.

---

## Live Demo

https://jiva-health-main.vercel.app

---

## Features

* Responsive healthcare dashboard UI
* Dynamic user details pages
* Functional tab system
* Orders, Payments & Family Members sections
* Mobile sidebar drawer
* Responsive layout for mobile, tablet, and desktop
* Zustand state management
* Modern reusable component architecture
* Figma-inspired UI implementation
* React Router dynamic routing

## Run Locally

Clone the project:

```bash
git clone <your-repo-link>
```

Go to the project folder:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```
